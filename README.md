# Hangman

A simple Hangman game built in Python.

## Features
- Random word selection;
- Letter guessing;
- Lives system;
- Win / lose conditions;
- ASCII art stages;
- Separate modules for words and ASCII art.

## Project structure
- `main.py` → main game logic;
- `hangman_words.py` → word list;
- `hangman_ascii.py` → logo and stages.

## What I practiced
- loops;
- conditionals;
- lists;
- string building;
- imports between Python files;
- game logic.

## How to run
Run `main.py` in PyCharm or terminal.
